# 《造化笔》

**一款专注写作的软件。**

造化笔是一个 **Windows 单机离线的本地小说创作软件**：写长篇小说时，角色、设定、时间线、正文互相联动，稿子只存在你自己电脑上的一个文件夹里。

一句话说明它是什么：

> 给写长篇小说的人用的本地写作工具 —— 纯离线、完全免费、不用注册，你的稿子不在任何服务器上。

---

## 它解决什么问题

写长篇最难受的两件事：**稿子丢了**，和**写着写着忘了前面写过什么**。造化笔主要就为这两件事做的。

### 一、不丢稿

- **停笔自动保存**；手一直不停打字也不会一直等 —— 连续输入最长攒 **12 秒**就强制落盘一次。
- **崩溃草稿**：输入期间会往本机写一份应急副本（不写进书夹、不联网）。断电、死机、被任务管理器强杀之后，下次启动会提示「发现 N 条未落盘的正文草稿」，可以选择恢复。
- **整书快照**：自动为整本书拍快照（结构 / 正文 / 角色库 / 设定库 / 时间线 / 元数据），支持整书回滚，也支持**选择性回滚** —— 例如只把正文退回三天前，角色和设定一条都不动。
- 界面上**没有保存按钮**，因为不需要按。

### 二、角色和正文是连着的

- 正文编辑器右上角有一栏「关联角色」，只列出正文里真的出现过的角色。
- 点一下就是**标记登场**，再点一下取消；标记过的场景会按章节顺序，自动记进这张角色卡的「经历」。
- 点经历里的某一条，直接跳回正文那一段；从正文也能一键跳回卡片。
- 角色卡本身是结构化的（姓名 / 别名 / 身份 / 外貌 / 性格 / 动机 / 关系），改完自动保存。

### 三、大纲、关系、设定都摆得开

- **故事线**是一块能画的板子：节点自由嵌套，最里层就是正文；图形能像窗口一样拖大小、改形状与字号，选中几个可以一起缩放、一起旋转。
- 板子底部挂着**时间线停靠条**（照着剪辑软件做的）：一排轨道、事件块能拖着换轨换位，轨道自己加、颜色和名字随你起；双击一个事件还能进它的「子事件层」，一层层钻下去再退回来。
- **分区**把一章的节点圈成一块，折叠起来只留一条标题；**锁定**的图形点得到、拖不动；**隐藏**的连同子图形一起从画布、导出和搜索里消失。
- **互链卡片**：把角色 / 设定 / 事件卡摆到画布上，卡面显示的是实体本身 —— 在别处改了名，卡面立刻跟着变。画布还能**导入 / 导出 Obsidian JSON Canvas**（`.canvas`），跟别的白板工具互通。
- **关系图谱**：点一张角色卡就点亮他一圈邻居，其余淡下去；关系台账按类型一行行列全，行内能改类型、方向、备注；排不开就一键力导向重新聚拢。
- 角色卡里的字段可以**自己排**（两列 / 单列、上下调序、半行或整行、加自定义字段）；角色、设定、势力都能放**多张图**，第一张自动当封面，一次选多张批量加进去。
- **导出可以直接复制**：整本、框选范围、单章都能一键进剪贴板（纯文本或 Markdown），不用先存文件再打开。

### 四、数据和软件都在你自己手里

- 稿子不在任何服务器，就在本机一个叫**书夹**的文件夹里；整个文件夹拷走就是全部本地数据。
- 正文是 **Markdown**，结构与设定是 **JSON**。真急眼了，用记事本也能把稿子抢救出来。
- **纯离线**：不配置任何东西、不打开任何开关，基础功能一个都不少。

## 主要功能

**一本书就是一个项目。** 左边是故事线，节点可以一层层嵌套，最里面那一层就是正文编辑器；主线顺序会自动拼成书，卷和章的标题也一并带上。单本写到千节点这个量级也是它的设计目标。

| 板块 | 做什么 |
|---|---|
| 故事线 | 大纲与正文合一的画布，节点自由嵌套，最内层就是正文编辑器；支持分区、锁定、隐藏、互链卡片；底部时间线停靠条多轨、可预合成 |
| 关系图谱 | 角色关系单独成图，可聚焦邻居、按类型台账维护、力导向重排 |
| 角色库 | 结构化角色卡，与正文双向联动，经历按章节自动生成；版式与图集可自定义 |
| 设定库 | 卡片墙式设定管理，按分类归置 |
| 时间线 | 事件按时间排布，配合世界观使用；主入口在故事线底部停靠条，也保留独立页 |
| 世界观总库 | 「世界（世界观）」是书架之上的顶层实体，可让多本书共享角色 / 设定 / 时间线 / 事件表，每本书仍可独立成书导出 |
| 统计目标 | 写作统计、目标进度、番茄钟、实时字数窗、历史快照与回滚 |
| 全局搜索 | 全书检索，带本地索引 |
| 灵感速记 / 素材收藏 | 随手记点子、存素材，可分类 |
| 一致性检查 | 查设定与正文的冲突；只重扫改过的段落，可开独立小窗 |
| 插件 | 本地 JS，目录即装、有权限声明、跑受限沙箱、默认全部停用 |

## AI：默认关闭

AI 相关功能**默认是关的**（设置 → AI 里的「AI 总开关」，默认关闭就是零联网）。不配置 Key、不打开开关，基础功能一个不少。想用的时候有两样东西：

1. **MCP 接口** —— 外部支持 MCP 的 AI 助手可以连上它，读你的书、帮你改稿。默认不开，开了也只绑本机回环地址，连接信息一键复制，API Key 一直是你自己的。
2. **插件系统** —— 别人可以给它加功能。插件是本地 JS，目录即装，有权限声明，跑在受限沙箱里，默认全部停用，高风险权限需要单独授权。

这两样是给愿意折腾的人准备的，不爱折腾完全不影响使用。

## 关于收费

**完全免费。** 没有付费版，没有激活码，没有账号，没有广告，也没有「解锁功能」这种收费方式 —— 你现在用到的就是完整版。

它也不管云备份，定位就是本地。**暂时只有 Windows 版**，没有其他系统的版本。

## 下载安装

本仓库只放**安装包**与校验和，不含源码。最新版 **v0.5.2**。

1. 到 [Releases](../../releases) 选最新版，下载 `ZaoHuaBi-<版本>-win-x64.exe`。
2. 双击安装。安装包未做代码签名，Windows 可能弹「未知发布者」的 SmartScreen 提示 —— 点「更多信息」→「仍要运行」即可。
3. 想核对完整性，用同一 Release 里的 `SHA256SUMS.txt`。

### 应用内更新

应用的更新源默认指向本仓库的 Releases（公开仓库，免令牌），在应用里 **设置 → 关于与性能 → 更新与备份** 可以更新。升级前会自动把当前数据备份到书夹旁的 `_zaohuabi_backup/upgrade_v<旧版本>_to_v<新版本>_<时间戳>`，出错可回退。

每个 Release 的说明文字就是该版本的更新日志，应用里的更新卡片也能直接看到。
